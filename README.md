# iGaming Payments Broker

Единый рабочий репозиторий для развития независимого B2B-направления:
подбор платёжных, crypto и dispute-решений для лицензированных iGaming-операторов.

## Цель

Построить дополнительный источник дохода до **$5 000 в месяц**, уделяя проекту
в среднем **1 час в день**. Модель дохода: referral fee, revenue share и, позднее,
оплата за квалифицированное сопровождение подключения.

## Текущий статус

- Ниша предварительно выбрана: payment и dispute solutions для лицензированного iGaming.
- Рыночная боль подтверждена кабинетным исследованием.
- Главная неподтверждённая гипотеза: операторы готовы работать с новым независимым
  посредником без публичного track record.
- Следующий этап: найти 2 подходящих провайдера и провести 100 точечных касаний
  с мерчантами.

Актуальная точка продолжения находится в
[`docs/session-handoff.md`](docs/session-handoff.md).

## Как продолжать с другого устройства

1. Клонировать репозиторий и открыть его в Codex как проект.
2. В начале работы выполнить `git pull --ff-only`.
3. Попросить Codex прочитать `AGENTS.md` и `docs/session-handoff.md`.
4. После значимой сессии обновить `docs/session-handoff.md`; при новом стратегическом
   решении также обновить `docs/decision-log.md`.
5. Закончить работу коммитом и push.

Если два устройства работают одновременно, каждое использует отдельную короткую
ветку, а не редактирует `main` параллельно.

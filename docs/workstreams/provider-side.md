# Поток Provider Side

Обновлено: 2026-08-05.

## Миссия

Найти минимум два проверенных решения, которые можно честно и защищённо
предлагать одному узкому сегменту licensed iGaming operators.

## Текущий статус

- Этап: первый партнёрский outreach, ожидание ответов.
- Проверено провайдеров: 4 из 12–15.
- Прошло обязательные фильтры: 0.
- Выбрано для контакта: 4 из 6.
- Отправлено партнёрских обращений: 4.
- Проведено партнёрских разговоров: 0 из 6.
- Получено письменных комплектов условий: 0 из 3.
- Active providers: 0 из 2.
- Provider gate: **не пройден**.

Нули означают отсутствие результатов, зафиксированных в репозитории, а не
утверждение, что работа вне репозитория не проводилась.

## Очередь задач

1. Подготовить приватную рабочую таблицу по полям из `provider-scorecard.md`.
2. Проверить четыре crypto gateways по обязательным фильтрам.
3. Проверить четыре dispute/chargeback providers.
4. Проверить 4–7 PSP, APM или orchestration providers с явным iGaming fit.
5. Оценить кандидатов и выбрать шесть для партнёрского разговора.
6. Подготовить персонализированный partner pitch и список открытых вопросов.
7. После прямого разрешения пользователя провести первые контакты.
8. Получить письменные acceptance, terms и lead-registration rules.
9. Выбрать два Active providers с дополняющим coverage.

## Definition of done

Поток завершает текущий этап, когда:

- два провайдера проходят обязательные фильтры;
- их acceptance matrix и commercial terms подтверждены письменно;
- понятны lead protection, reporting, payout и clawback;
- есть официальный контакт для pre-check и escalation;
- из coverage можно вывести один конкретный merchant-сегмент.

### 2026-08-05 — Отправлены первые четыре партнёрских обращения

Проверено публичное позиционирование и отправлены обращения в NOWPayments,
Payhound, FinXP и Corefy. Все четыре кандидата переведены в статус **Contacted**;
ответов сотрудников, партнёрских разговоров и письменных комплектов условий пока
нет. Автоматическое подтверждение NOWPayments фиксирует только получение письма и
не считается подтверждением коммерческих условий.

Запрошены accepted gambling licences и player GEOs, restricted jurisdictions,
анонимизированный pre-check, требования к объёму и processing history, правила
lead registration и attribution, формула и срок комиссии, reporting, payout,
clawback и требования к юридическому статусу introducer.
